### 2.2 바꾸면 같이 움직이는 것 (②)

| 종류 | 같이 움직이는 것 | 확인한 것 |
|---|---|---|
| 테스트 이름 | 없음. 이름만 보고 판정하는 코드가 없다 | Kotest 가 이름으로 테스트를 고르는 설정은 없다. CI 도 모듈 단위로 돈다 |
| 스크립트 출력 | 없음. 출력을 grep 하는 곳이 없다 | `check-pipeline.sh` · `check-wiring.sh` 는 로그 줄 `'OTLP gRPC 수신 시작'` 을 **사람에게 찾아보라고** 안내만 한다. 그 머리말은 옛 용어가 아니라 그대로 남는다 |
| 화면 문구 | 없음. 화면 글자를 찾는 web 테스트는 없다 | `*.test.tsx` 에서 `getByText` 류로 옛 용어를 찾는 곳 0. web 의 테스트 3건은 테스트 **이름**이다 |
| Slack 경보 | watchdog 테스트 3줄이 경보 글자를 검사한다 (`test_handler.py:108,124,125`) | 같이 고친다. Slack 채널을 키워드로 거르는 설정이 있는지는 **확인 못 했다** |
| 로그 문구 | 우리 로그를 글자로 거르는 경보 규칙은 아직 없다 (로그 경보 `#230` 은 열려 있고 미구현) | 다만 Self-monitoring 으로 우리 로그도 `logs` 표에 쌓인다 : 옛 글자로 검색하던 사람은 새 글자로 찾아야 한다 |
| 지표 설명 | `/actuator/metrics/<이름>` 의 `description` 칸에만 보인다. 지표 **이름**(`monimo.collector.otlp.received`)은 안 바뀐다 | 화면 · 경보는 이름으로 읽는다 |
| API 응답 메시지 | ① 노션 API 명세 본문 ② web 가짜 응답(`mocks/threadDumps.ts:199`) · 화면이 메시지를 그대로 보여 주는 곳(`DumpRequestModal.tsx:26` 은 코드를 보고 **자기 글**을 쓴다) ③ api-server 테스트는 이 메시지를 비교하지 않는다 (grep 0) | 화면은 메시지가 아니라 `code` 로 가른다(`AGENT_NOT_REACHABLE`). 메시지를 바꿔도 화면 분기는 안 깨진다 |
| 시드 데이터 | 화면 「설정 › 서비스」 의 **표시 이름 · 설명**으로 보인다 | 로컬 · CI 에서만 쓰는 값이다. 운영은 설정 화면에서 넣는다 |
| 라벨 설명 | `setup-labels.sh` 를 다시 돌려야 GitHub 에 반영된다 | 라벨 **이름**(`area/collector`)은 이미 영어다 |

### 2.3 데이터는 어디로 흐르나 (문자열이 사람에게 닿는 길)

```
테스트 이름      → Gradle · vitest 결과 화면 (개발자)
스크립트 출력    → 터미널 · CI 로그 (개발자)
로그 문구        → 파드 stdout → (Self-monitoring) Collector → ClickHouse logs → 화면 로그 검색 (운영자)
지표 설명        → /actuator/metrics (개발자)
API 응답 메시지  → 화면이 받는 에러 봉투 message (사용자가 볼 수 있다) · 노션 명세
화면 문구        → 브라우저 (사용자)
Slack 경보       → 팀 Slack 채널 (사람)
시드 데이터      → PG applications → 설정 화면 (사용자)
```

| 질문 | 답 |
|---|---|
| 사용자 눈에 직접 닿는 것 | 화면 문구 · Slack 경보 · API 응답 메시지 · 시드 표시 이름 |
| 개발자만 보는 것 | 테스트 이름 · 스크립트 출력 · 지표 설명 · 라벨 · CI 단계 |
| 글자를 기계가 읽는 것 | watchdog 테스트의 경보 글자 비교 3 줄뿐 |

### 2.5 자주 헷갈리는 것

| 헷갈리는 것 | 실제 |
|---|---|
| 문자열을 바꾸면 동작이 바뀐다 | 대부분 아니다. 글자를 비교하는 곳은 watchdog 테스트 세 줄뿐이고 그 테스트도 같이 고친다. 화면 분기는 `code` 로 한다 |
| 지표 설명을 바꾸면 대시보드가 깨진다 | 아니다. 대시보드 · 경보는 지표 **이름**으로 읽는다. 설명은 사람용이다 |
| 로그 문구는 절대 못 바꾼다 | 우리 로그를 글자로 거르는 규칙은 아직 0 개다. 다만 바꾸면 옛 글자로 검색하던 습관이 끊긴다 |
| 화면 메뉴를 영어로 바꾸면 피드백과 맞는다 | 멘토 피드백은 **문서 · 설계 설명**의 용어였다. 화면 메뉴 언어는 제품 결정이다 (Pinpoint 는 ServerMap · Inspector 를 영어 그대로 쓴다) |
| 응답 메시지는 명세가 정본이라 못 바꾼다 | 바꿀 수는 있다. 그때 노션 명세 본문도 같이 고친다 |
